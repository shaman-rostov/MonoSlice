The latest version of MonoSlice is available on GitHub Releases.

[Download MonoSlice](https://github.com/shaman-rostov/MonoSlice/releases)

## Installation Package

MonoSlice is distributed as a macOS DMG application.

Installation steps:

1. Download the latest `.dmg` file.
2. Open the downloaded file.
3. Drag MonoSlice to the Applications folder.
4. Launch MonoSlice.

---

## System Requirements

### macOS

MonoSlice requires **macOS 12.0 Monterey or newer**:

- macOS 12 Monterey
- macOS 13 Ventura
- macOS 14 Sonoma
- macOS 15 Sequoia

## Verify Download

Each release includes:

- Application version
- Release notes
- SHA-256 checksum

You can verify the downloaded file integrity before installation.

Example:

```bash
shasum -a 256 MonoSlice.dmg
```

Compare the result with the checksum provided in the release notes.

## Security Notice

MonoSlice is distributed outside the Mac App Store.

macOS may display a security warning when launching the application for the first time.

If this happens:

1. Open **System Settings**.
2. Go to **Privacy & Security**.
3. Allow MonoSlice.
