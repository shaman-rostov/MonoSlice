# Privacy Policy

## MonoSlice Privacy Statement

MonoSlice is designed with privacy in mind.

The application works locally on your Mac and does not require uploading your files or applications to external servers.

---

## Data Processing

MonoSlice processes application files directly on your computer.

The application may access:

- Applications selected by the user
- File system locations chosen by the user
- Application metadata required for optimization

This data is processed locally.

---

## Data Collection

MonoSlice does not collect:

- Personal information
- Application contents
- User documents
- File names
- Usage history
- Analytics data

---

## Network Access

MonoSlice does not access the network. It makes no network connections and works fully offline.

Updates, documentation and support are available on GitHub and are opened in your web browser, not by MonoSlice itself.

---

## Application Security

MonoSlice modifies application binaries only when explicitly requested by the user.

The application does not:

- Modify macOS system files
- Install background services
- Monitor user activity
- Run hidden processes

---

## Third-Party Services

MonoSlice may use third-party services for:

- Software distribution
- Project hosting
- Donations
- User support

These services have their own privacy policies.

---

## Changes to This Policy

This privacy policy may be updated as MonoSlice evolves.

The latest version will always be available in this repository.

---

## Contact

For privacy questions or concerns, please open a GitHub Issue or contact the project maintainer.
